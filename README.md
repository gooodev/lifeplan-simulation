# ライフプラン・シミュレーション

家族構成・収支・住宅・教育・年金などの条件を入力すると、年次キャッシュフロー表と
貯蓄残高の推移をその場で試算できる、個人向けのライフプラン試算アプリ。

以前 FP に依頼して作成した帳票（`docs/private/lifeplan.pdf`）と同等の試算を、
自分たちの手で何度でもやり直せるようにするために作った。詳しい計算根拠は
[`docs/SPEC.md`](docs/SPEC.md) を参照。

## データの扱いについて

**すべてのデータはブラウザ内（localStorage）だけに保存され、外部には一切送信されない。**
サーバーもデータベースも持たない静的サイト（TanStack Start を SPA モードで使用し、
ビルド後はプレーンな静的ファイルとして配信できる）。

- バックアップ・他のブラウザへの引き継ぎは、画面上部の「JSONエクスポート」「JSONインポート」で行う
- `docs/private/` はこのリポジトリに含まれる個人の家計情報用フォルダで、`.gitignore` により
  コミット対象から常に除外される
- 複数タブを開いている場合、状態管理に TanStack DB（`src/store/collections.ts`）の
  localStorage コレクションを使っているため、片方での変更がもう片方にリアルタイムで反映される

## 使い方

```bash
pnpm install
pnpm dev
```

`http://localhost:5173` を開く。

- **プロフィール・前提**: 家族構成、試算期間、運用利回りなどの前提条件
- **ライフイベント**: 給与・住宅購入・教育費・年金・保険・旅行など、すべてのイベントをここで
  追加・複製・無効化する
- **サマリー / 年表 / キャッシュフロー表 / 各種グラフ**: 試算結果の確認
- **プラン比較**: プランを複製して条件を変え、貯蓄残高の推移を重ねて比較する

## 開発

```bash
pnpm run check   # 型チェック・lint・フォーマット
pnpm run test    # ドメイン層（計算エンジン）のユニットテスト
pnpm run build   # 本番ビルド
```

計算エンジン（`src/domain/`）はUIに依存しない純粋関数として実装されており、
テストは個人の家計データを一切使わず、架空の値だけで検証している。
